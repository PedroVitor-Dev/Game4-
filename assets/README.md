# Original Game4∞ artwork

These four 500 × 500 PNG files were supplied by the project owner and are kept unchanged:

- `White_SF.png`: white artwork on a transparent background; used on the app's dark surfaces.
- `Black_SF.png`: black artwork on a transparent background; suitable for light surfaces.
- `Logo_Black.png`: white artwork with an opaque black background.
- `Logo_White.png`: black artwork with an opaque white background.

The symbol and wordmark are language-neutral. These are background/color variants; English and Brazilian Portuguese text is provided by the app's locale files. Imports reference this directory directly so the repository and app use the same originals.
